# BTX AutoCount MCP Connector: installers

This repository only holds the installers that the **AutoCount MCP Manager** downloads for in-app updates
(Manager → Settings → Updates). The source code is not published here.

- **Stable** releases: tested versions for customers.
- **Pre-releases** (`-test`): newest versions for testing; may still have bugs.

Every installer comes with a `.sha256` file. The Manager refuses to install a download whose checksum does not match.
